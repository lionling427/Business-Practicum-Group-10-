# Synthetic test data: long_main
Generated by generate_synthetic_data.py v3.0 with seed 1, variant `long_main`.
Main truths over 5 yearly waves, with manager changes and three planted events (E1 better manager, E2 worse manager, E3 inflated scores). Tests trends and team predictions.
## Size
| Item | Value |
|---|---|
| Employees per wave | 50,000 |
| Survey waves | 5 |
| Survey rows | 250,000 |
| Teams | 4,000 |
| Teams with fewer than 5 people | 200 (5.0%) |
| Departments | 8 |
| Wave 1 response rate | 81.4% |
| Wave 1 voluntary turnover | 18.3% |
## Files
| File | Who may read it | Contents |
|---|---|---|
| `agent_data/survey_responses.csv` | Agent | One row per employee per wave: Q01-Q12 (blank for non-respondents), department, tenure, role, pay band, shift, survey date, manager_id (changes when a team gets a new manager) |
| `agent_data/individual_outcomes.csv` | Agent | Turnover (12 months), unplanned absence days (6 months), prior and current performance rating, and the date each outcome window ends. Wave 5 outcomes are blank: that year has not finished |
| `agent_data/team_outcomes.csv` | Agent | Team id, department and team size per wave |
| `answer_key/ground_truth.json` | Graders only | Planted settings, realized values, true nulls, traps, seed |
| `answer_key/teams_with_manager_quality.csv` | Graders only | Hidden manager quality per team (trap X3) |
| `answer_key/hidden_outcomes.csv` | Graders only | The newest wave's real outcomes (blank in agent_data), for grading forecasts |
| `answer_key/manager_changes.csv` | Graders only | Every manager change: wave, team, reason, hidden quality before and after |
| `answer_key/team_true_risk.csv` | Graders only | True expected turnover per team per wave |
| `answer_key/events.csv` | Graders only | Teams hit by the planted events E1, E2, E3 |

Never give the agent anything in `answer_key/`.

## Rebuild

```bash
python generate_synthetic_data.py --employees 50000 --seed 1 --variant long_main --out long_main
```

The same command always produces identical files.
